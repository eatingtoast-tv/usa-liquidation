# USA Liquidation admin (admin.usaliquidation.shop)
Deployed to Vercel from THIS folder only (`npx vercel --prod` here). The public site stays on GitHub Pages.
Env vars (set in Vercel → Settings → Environment Variables): ADMIN_USERNAME, ADMIN_PASSWORD, ADMIN_SECRET,
NOTION_TOKEN, GEMINI_KEY, optional GH_TOKEN (instant site refresh), optional GEMINI_MODEL.
